# UNOOL（UNO Online）规则## 框架规则游戏层次分为 **场、局、轮、回合、阶段**。1. **场（Match）**   - 一场游戏开始，双方进行 BP（双方各出现 10 个角色，ban 对方两个角色）。   - 一场游戏分为数局。   - 一名角色体力值归零时，一场结束。   - 体力值归零的角色输，另一名角色获胜，获得积分。   - 积分获取与角色等级有关：低等级战胜高等级时获得较多积分，反之获得少量积分。   - **满血获胜得分翻倍**。2. **局（Game）**   - 一局完整的 UNO 游戏。   - 一名角色失去所有手牌时一局结束，该玩家获胜。   - 其他玩家扣减体力，扣减值等同于其手中剩余牌的总分值：     - 数字牌：分值为牌面数字     - 功能牌：20 分     - 万能牌：50 分3. **轮（Round）**   - 所有角色依次进行过操作。   - 从一号位玩家回合开始到末号位玩家回合结束视为一轮。   - 封禁不影响回合进行。4. **回合（Turn）**   - 一名角色进行操作的时段。   - 进入回合为**首个出牌阶段**，此阶段出牌后进入**结束阶段**。   - 若未跟牌则须进行**摸牌阶段**，摸一张牌，再进行**第二个出牌阶段**：     - 若摸牌阶段摸到的牌能打出则可打出（也可不出），随后结束回合。5. **阶段（Phase）**   - 在阶段内进行操作，依次为：     - 准备阶段     - 出牌阶段 1     - 摸牌阶段     - 出牌阶段 2     - 结束阶段---## 基础规则### 1. 牌堆构成（共 174 张牌）| 类别 | 牌种 | 数量 | 说明 ||------|------|------|------|| **数字牌** | 0 | 每种颜色 2 张 | 共 4 色 × 2 = 8 张 || | 1~9 | 每种颜色 3 张 | 共 4 色 × 9 × 3 = 108 张 || **功能牌** | 封禁牌 | 每种颜色 3 张 | 共 4 色 × 3 = 12 张 || | 反转牌 | 每种颜色 3 张 | 共 4 色 × 3 = 12 张 || | +2 牌 | 每种颜色 4 张 | 共 4 色 × 4 = 16 张 || **万能牌** | 变色 | 10 张 | — || | +4 牌 | 8 张 | — |### 2. 开局- 每局游戏开始时**随机分配座位**。- 每名玩家各**摸 8 张牌**。- 根据座位号轮流进行回合。### 3. 出牌规则1. 若没有上一张牌，可随便出牌。2. 否则只能打出与**当前颜色相同**或与**当前牌名相同**的牌。3. 无论上一张牌为什么牌，均可打出**万能牌**。### 4. 功能牌和万能牌效果| 牌类型 | 效果 ||--------|------|| **反转牌** | 调转当前出牌顺序（顺时针 ↔ 逆时针） || **封禁牌** | 令下家跳过其下一个回合 || **+2 牌** | 令下家跳过其下一个回合，且其摸两张牌 || **万能牌（变色）** | 改变当前颜色 || **+4 牌** | 改变当前颜色，然后下家须选择是否质疑：<br>• **不质疑**：下家跳过其下一个回合，并摸 4 张牌<br>• **质疑且成功**（你手中有变化前公共颜色的牌）：你摸 4 张牌<br>• **质疑失败**：下家跳过其下一个回合，并摸 6 张牌 |
